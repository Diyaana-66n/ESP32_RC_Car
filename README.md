# ESP32-Based Wi-Fi Controlled RC Car

A four-wheel robotic car developed using ESP32 and L298N motor driver, controlled wirelessly through a smartphone-based web interface.

### Features
- Wi-Fi-based wireless control.
- Forward, backward, left and right movement.
- Browser-based control without a dedicated mobile application.

### Components
ESP32, L298N Motor Driver, 4 DC BO Motors (100 RPM), chassis, wheels, 18650 batteries and jumper wires.

### Technologies
Embedded C, Arduino IDE, ESP32, Wi-Fi and HTML.
